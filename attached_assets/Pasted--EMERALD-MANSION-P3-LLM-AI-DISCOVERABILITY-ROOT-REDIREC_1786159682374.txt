# TASK 1 – ROOT 302 → 301 PERMANENT REDIRECT

Production üzerinde şu davranış mevcut:

Request:

https://emeraldmansion.com/

Current response:

HTTP 302 Found

Location: /en/

Bu davranışı değiştir.

Root `/` kalıcı olarak English homepage `/en/` URL'sine yönleniyor.

Bu nedenle:

https://emeraldmansion.com/

şu response'u vermeli:

HTTP 301 Moved Permanently

Location: /en/

Tercihen mevcut Express redirect architecture içerisinde 301 kullan.

Örneğin mevcut framework mantığına uygun biçimde:

res.redirect(301, "/en/")

benzeri bir implementation.

Framework'e uygun gerçek yöntem neyse onu kullan.
